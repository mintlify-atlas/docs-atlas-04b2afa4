Vesper is an open-source OSINT engine built for speed. It searches hundreds of websites simultaneously for a given username, fusing the power of three leading databases — WhatsMyName, Sherlock, and Maigret — into a single binary with zero runtime dependencies. Benchmarked at up to **3× faster** than competing tools, Vesper completes a full WhatsMyName scan in around 21 seconds.

## Why Vesper?

Vesper is designed for OSINT investigators and security researchers who need results fast. It uses 250 concurrent Go goroutines to fire HTTP checks against every site in the selected database simultaneously, with a configurable timeout so you control the speed–thoroughness tradeoff.

## Quick Example

```bash
# Search for a username using the default WhatsMyName database
./vesper john_doe

# Use all three databases at once
./vesper --database all john_doe

# Adjust timeout for slower networks
./vesper --timeout 12 john_doe
```
