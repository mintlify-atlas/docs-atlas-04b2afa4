Vesper is an open-source OSINT command-line tool written in Go that hunts down usernames across hundreds of websites in seconds. Instead of querying a single database, Vesper fuses three battle-tested intelligence sources — WhatsMyName, Sherlock, and Maigret — into one unified engine. Whether you are performing a reconnaissance investigation, auditing your own digital footprint, or researching a target username for defensive security purposes, Vesper gives you broad cross-platform coverage from a single command.

## What Problem Vesper Solves

Existing username-enumeration tools are either slow (running requests sequentially or with low concurrency) or limited to a single site database. Vesper addresses both constraints. It spawns **250 concurrent goroutine workers** that drain a buffered job channel, saturating available network bandwidth and completing a full WhatsMyName sweep in roughly 21 seconds on commodity hardware — up to 3× faster than tools like [Blackbird](https://github.com/p1ngul1n0/blackbird).

## Integrated Databases

Vesper compiles all three site lists directly into the binary at build time, so there are no external files to manage.

| Database | Role | Notes |
|---|---|---|
| **WhatsMyName** | Primary, balanced coverage | Stable, recommended for most searches |
| **Sherlock** | Social media focus | May produce false positives |
| **Maigret** | Broadest coverage, niche sites | May produce false positives |

<Note>
  Only the WhatsMyName database is considered stable at this time. Sherlock and Maigret are included for breadth but are known to produce false positives. Start with WhatsMyName for the most reliable results.
</Note>

## Key Differentiators

- **250 goroutine workers** running concurrently against a 1 000-entry buffered job channel
- **~21 s** for a full WhatsMyName sweep, ~12 s for Sherlock, ~33 s for Maigret
- **Up to 3× faster** than Blackbird on the same hardware
- **Zero external dependencies at runtime** — site data is compiled into the binary via metaprogramming
- **Two interaction modes** — a traditional CLI and an interactive terminal UI built with [Bubble Tea](https://github.com/charmbracelet/bubbletea)

## Performance Benchmarks

Benchmarked on Arch Linux with an AMD Ryzen 7 5000 Series CPU and 16 GB RAM.

| Database | Average Execution Time |
|---|---|
| WhatsMyName | ~21 seconds |
| Sherlock | ~12 seconds |
| Maigret | ~33 seconds |

## Two Modes of Operation

**CLI mode** accepts a positional username argument along with optional flags and streams results directly to your terminal as each match is discovered.

**TUI mode** (`--tui`) launches a full-screen Bubble Tea interface that guides you through three phases: entering a username, selecting a database from an interactive list, and watching a live progress bar before displaying results in a sortable table.
